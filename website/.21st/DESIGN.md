# Domiorum design context

Architecture and interiors portfolio using Next.js, React and Tailwind 4.

Use tokens from src/styles/globals.css: navy #08182e, ivory #f6f3ed, gold #e1bf77 and ink #29313a. Retain Jost and the client-selected serif project titles.

Reuse DirectionalArrow, FlowButton, HoverText and LinkButton. Preserve real project images, keyboard navigation, reduced motion and native scrolling. Portfolio motion uses scroll-linked parallax, image zoom and title drift. Project detail pages use sticky layered scenes, horizontal-strip image wipes, masked room-title reveals and expanding covers inspired by the live Elyse reference. Reduced motion renders every image in ordinary page flow; a visible control allows explicit session opt-in. Homepage additions inspired by Wiemer and Eladio Dieste use opposing hero title drift, masked heading lines, readable word colour progression and expanding photo frames. They add no scroll pins and restore original styles when motion is disabled. Further guidance: DESIGN.md.
